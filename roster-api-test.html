🏈 Fantasy Roster API Lab

Test league roster imports from Sleeper, ESPN and Yahoo without touching the main Fantasy Football app.

No authentication required. Loads league, users, rosters and Sleeper's NFL player directory.
Uses ESPN's unofficial fantasy endpoint. Public leagues may work directly. Private leagues can reject browser requests because authentication cookies/CORS are controlled by ESPN.
Yahoo requires approved API access + OAuth 2.0. A numeric league ID alone is not globally unique; Yahoo's league key is gameKey.l.leagueId. Token is used only for this request and is not stored.
